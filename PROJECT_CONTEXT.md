# 📋 ПАСПОРТ ПРОЕКТА YourNails

## 🎯 Общая информация
- **Название:** YourNails
- **Тип:** Мобильное приложение (Flutter)
- **Платформа:** Android (MVP)
- **Целевая аудитория:** Мастера маникюра и нейл-салоны

## ✅ Реализованный функционал

### 1. Примерка дизайна (EditScreen → ResultScreen)
- Загрузка фото пальца (камера / галерея)
- Pinch-to-zoom и перемещение фото жестами
- Настраиваемая рамка ногтя (ширина, высота, поворот, позиция)
- 5 форм ногтя: Овальная, Круглая, Квадратная, Мягкий квадрат, Квадратно-овальная (анатомически правильные: низ всегда скруглён)
- Кнопка 👁 скрытия рамки для оценки результата
- WYSIWYG: что видишь в настройке = что получаешь в результате = что сохраняется
- **Сессия примерки:** состояние (фото, рамка, зум, дизайн, 3D, кутикула) сохраняется в Hive при любом выходе; при входе — диалог «Продолжить / Начать заново»; переживает перезапуск приложения
- **Быстрое меню (⋮):** из примерки открываются «Клиенты» и «Мои дизайны» поверх (примерка остаётся в стеке — состояние не теряется)
- **Реалистичный 3D-рендер:** см. раздел «3D-пакет»

### 2. Выбор дизайна (DesignSelectionScreen)
- Цвет: 60 встроенных цветов в 8 группах + трендовые палитры + «Мои цвета»
- Материал: 5 типов (Гель-лак, Гель, Акрил, Биогель, Обычный лак) с визуальными эффектами
- Рисунок: 7 базовых паттернов + узоры-картинки
- Все данные — из Единой Библиотеки (`UnifiedLibraryService`)
- Превью сохранённых рецептов — WYSIWYG через тот же `Nail3DRenderer`
- **Карточка цвета:** тап по полоске с именем в пикере → свотч, группа, HEX, рецепт (description), кнопки Выбрать/Удалить

### 3. Миксер цветов (ColorMixerScreen)
- Смешивание двух цветов (A + B) с ползунком пропорции
- Добавление белил и затемнения
- Сохранение в «Мои цвета»: авто-имена **«Микс №N»** (сквозная нумерация), полный рецепт сохраняется в `description`
- Применение без сохранения: временное имя = полный рецепт (хорошо читается в саммари)
- Применение из миксера возвращает на «Выбор дизайна» с уже подставленным цветом

### 4. Клиенты и визиты (ClientDetailScreen)
- Локальная база клиентов (Hive)
- Добавление/удаление клиентов
- Визиты с тремя фото: ДО / ПРИМЕРКА / ПОСЛЕ
- Полноэкранный просмотр фото с жестами зума
- Управление фото: удаление (с подтверждением) и замена из галереи
- Автоудаление пустого визита (клиент остаётся)
- CRM-данные: цена визита, название услуги (используются в статистике и напоминаниях)

### 5. Выравнивание «ПОСЛЕ» по призраку (AlignAfterScreen)
- Выбор фото «после» ТОЛЬКО из галереи
- Полупрозрачный контур «ДО» поверх нового фото
- Жесты перемещения и зума для совмещения рук

### 6. Сохранение
- Сохранить клиенту: рендер примерки + фото «до» в базу (с одинаковым зумом мастера)
- В коллекцию: сохранение рецепта дизайна (цвет+материал+форма+3D+узор)
- В галерею: сохранение PNG-рендера через пакет gal

### 7. Видео до/после (AnimationScreen) — В РАЗРАБОТКЕ, ФАЗА 1 ЗАВЕРШЕНА
- Автоматическая анимация из фото визита
- **7 переходов:** Блёстки, Круг, Вспышка, Шторка, Зум-панч, Слайд, Фейд
- **5 трендовых шаблонов:** Слайдер, Вспышка, Обложка, **Reels** (вертикаль 1080×1920), **Кино** (16:9 с letterbox+grain)
- **4 классических шаблона:** Чистый, Instagram, TikTok, Гламур
- Ken Burns эффект (кадры «дышат»)
- Только MP4 экспорт через `flutter_quick_video_encoder` (без GIF)
- Сохранение в галерею + шеринг
- **Отмена экспорта:** кнопка ✕ рядом с прогресс-баром, `cancelChecker` прерывает рендер между кадрами, временный файл удаляется
- **Память последнего шаблона:** `last_video_template` в Hive settings, восстановление при следующем открытии
- **Имена файлов:** `{ИмяКлиента}_{YYYY-MM-DD_HHmm}.mp4` (в галерее и шеринге читабельные имена вместо timestamp)
- Мастер-бейдж (аватар + имя) в каждом шаблоне, адаптируется к размеру кадра

### 8. Единая Библиотека (Этап 1)
- `LibraryManifest` — метаданные (версия схемы, счётчики, группы цветов, дата обновления)
- `DesignLibrary` — агрегатор (цвета+материалы+паттерны) с fromJson/toJson и геттерами
- `BuiltinLibraryService` — встроенные данные: цвета из типизированного Dart-списка, материалы/паттерны из JSON-строки
- `UnifiedLibraryService` — единая точка доступа + кэш с `invalidateCache()`
- **Миграция старых ID:** `resolveColor()/resolveMaterial()`: кэш → `LegacyCatalog` → трендовые палитры
- `NailColor.description` — рецепт/описание цвета (миксы)
- Состав: 60 цветов (8 красных, 8 розовых, 8 нюд, 8 фиолетовых, 8 синих, 7 зелёных, 7 жёлтых, 6 тёмных), 5 материалов, 7 паттернов

### 9. Реалистичный 3D-рендер («3D-пакет»)
- Объём без чёрных оверлеев: производные тона самого лака (hue/saturation сохраняются)
- Поперечный купол (C-изгиб): светлая ось, тёмные бока того же тона
- Продольная арка по анатомии: тень валика у кутикулы (низ), светлая кромка торца (верх)
- Внутреннее свечение (глубина геля)
- Живой блик: наклонная полоса + гало + резкое ядро; адаптация к светлоте цвета и глянцу материала
- Тени: амбиент вокруг контура + направленная снизу
- Бороздка кутикулы только у основания ногтя (эффект «наклейки» устранён)
- Ползунки: «Объём» = купол+арка, «Блик» = зеркало, «Тень» = контактные тени

## 🔧 Технические заметки

### Единая Библиотека — использование
```dart
final colors = await UnifiedLibraryService.getAllColors();
final reds = await UnifiedLibraryService.getColorsByGroup('Красные');
final color = UnifiedLibraryService.resolveColor('red_wine'); // legacy ID
final color2 = UnifiedLibraryService.resolveColor('builtin_red_classic');
await UnifiedLibraryService.addCustomColor('Микс №5', color, description: 'рецепт…');
UnifiedLibraryService.invalidateCache();
```

### Жесты пикера цветов
- Тап по свотчу = выбрать цвет
- Тап по полоске с именем = карточка цвета (свотч, группа, HEX, рецепт, Выбрать/Удалить)
- Долгое нажатие = быстрое удаление своего цвета

### Имена миксов
- Сохранение без имени → «Микс №N» (сквозная нумерация по существующим)
- Рецепт (состав + белила/затемнение/пропорция) → `NailColor.description`
- Применение без сохранения → временное имя = полный рецепт

### Сессия примерки
- Hive box `tryon_session`, ключ `current`
- Фото копируется в `photos/tryon_*`
- Сохранение: `dispose()` EditScreen + перед ResultScreen
- Вход: `TryOnEntry.launch(context)`

### Модель рендера (SelectedDesign.getRender)
- `layerCoverage`: 1 → 0.88, 2 → 0.96, 3 → 1.00
- `opacity = material.opacity × layerCoverage`
- Насыщенность = множитель исходной (фикс HSL-бага)
- Яркость = множитель lightness (0.7–1.3)

### Слои RealisticNailPainter
1. Базовый цвет → 2. Купол → 3. Арка → 4. Свечение → 5. Паттерн → 6. Живой блик → 7. Глянец материала

### Анатомия координат painter'а
- НИЗ (y = height) = кутикула; ВЕРХ (y = 0) = свободный край

### Z-порядок в EditScreen (Stack)
1. Фон → 2. Ноготь → 3. Подсказка жестов → 4. Панель слоёв → 5. Нижняя панель

### Видео-рендер (VideoRenderer)
- `renderVideo(..., cancelChecker)` — проверка отмены перед каждым кадром
- Имена файлов: `{clientName}_{YYYY-MM-DD_HHmm}.mp4`, очистка спецсимволов
- Хранение последнего шаблона: `DatabaseService.lastVideoTemplate`
- Новые шаблоны:
  - **Reels** (`VideoTemplate.reels`): 1080×1920, cover-кроп, жирный шрифт 72px, розовая рамка 12px, тёмная подложка под заголовок, все 7 переходов
  - **Cinematic** (`VideoTemplate.cinematic`): 1920×1080, letterbox-полосы 140px сверху/снизу, зерно (grain intensity 10%), все 7 переходов, бейдж мастера приподнят над letterbox
- Архитектура: `VideoRenderer.paintFrame` для превью через `AnimatedBuilder` + `renderVideo` для экспорта (общий painter `_paintFrame`)

- `gal` — сохранение изображений и видео в галерею
- `flutter_quick_video_encoder` — кодирование MP4
- `image_picker` — камера/галерея
- `uuid` — идентификаторы
- `share_plus` — шеринг файлов
