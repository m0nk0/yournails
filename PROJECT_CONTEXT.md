# 📋 ПАСПОРТ ПРОЕКТА YourNails

## 🎯 Общая информация
- **Название:** YourNails
- **Тип:** Мобильное приложение (Flutter)
- **Платформа:** Android (MVP)
- **Целевая аудитория:** Мастера маникюра и нейл-салоны
- **Назначение:** Примерка дизайна ногтей на фото клиента перед процедурой + создание маркетингового контента (видео до/после)

## ✅ Реализованный функционал

### 1. Примерка дизайна (EditScreen → ResultScreen)
- Загрузка фото пальца (камера / галерея)
- Pinch-to-zoom и перемещение фото жестами
- Настраиваемая рамка ногтя (ширина, высота, поворот, позиция)
- 5 форм ногтя: Овальная, Круглая, Квадратная, Мягкий квадрат, Квадратно-овальная (анатомически правильные: низ всегда скруглён)
- Кнопка 👁 скрытия рамки для оценки результата
- WYSIWYG: что видишь в настройке = что получаешь в результате = что сохраняется

### 2. Выбор дизайна (DesignSelectionScreen)
- Цвет: 60 цветов в 8 группах с вкладками (Красные, Розовые, Нюд, Фиолетовые, Синие, Зелёные, Жёлтые, Тёмные) + группа "Мои цвета"
- Материал: 5 типов (Гель-лак, Гель, Акрил, Биогель, Обычный лак) с визуальными эффектами (глянец, матовость, прозрачность)
- Рисунок: базовые паттерны (в разработке)
- 3D-эффекты (регулируемые ползунками):
  - Объём (C-изгиб боков + радиальное затемнение)
  - Блик (световая колонна по центру + диагональный блик) — яркость 0.45, размытая через blur
  - Тень под ногтем
  - Слои лака (1-3): влияет на насыщенность и прозрачность
  - Яркость (0.7-1.3)

### 3. Миксер цветов (ColorMixerScreen)
- Смешивание двух цветов (A + B) с ползунком пропорции
- Добавление белил и затемнения
- Сохранение результата в "Мои цвета"
- Хранение в JSON-файле через CustomColorService

### 4. Клиенты и визиты (ClientDetailScreen)
- Локальная база клиентов (Hive)
- Добавление/удаление клиентов
- Визиты с тремя фото: ДО / ПРИМЕРКА / ПОСЛЕ
- Полноэкранный просмотр фото с жестами зума
- Управление фото: удаление (с подтверждением) и замена из галереи
- Автоудаление пустого визита (клиент остаётся)

### 5. Выравнивание "ПОСЛЕ" по призраку (AlignAfterScreen)
- Выбор фото "после" ТОЛЬКО из галереи (камера не поддерживается из-за ограничений системного видоискателя)
- Полупрозрачный контур "ДО" поверх нового фото
- Жесты перемещения и зума для совмещения рук
- Подсказка в пустой ячейке: "📸 Сделайте фото камерой, затем выберите здесь"

### 6. Сохранение
- Сохранить клиенту: рендер примерки + фото "до" в базу (с одинаковым зумом мастера)
- В коллекцию: сохранение рецепта дизайна (цвет+материал+форма+3D+узор)
- В галерею: сохранение PNG-рендера через пакет gal

### 7. Видео до/после (AnimationScreen) — В РАЗРАБОТКЕ
- Автоматическая анимация из фото визита
- 7 переходов: Блёстки, Круг, Вспышка, Шторка, Зум-панч, Слайд, Фейд
- 4 шаблона: Чистый (480×640), Instagram (640×640), TikTok (480×854), Гламур (480×640 с искрами)
- Ken Burns эффект (кадры "дышат")
- Только MP4 экспорт через flutter_quick_video_encoder (без GIF)
- Сохранение в галерею + шеринг

## 📐 Этапы развития

### ✅ ЭТАП 1: Единая Библиотека (ЗАВЕРШЁН)

| Шаг | Описание | Статус |
|-----|----------|--------|
| 1.1 | Модель `DesignLibrary` + `LibraryManifest` | ✅ Готово |
| 1.2 | Сервис загрузки встроенной библиотеки (`BuiltinLibraryService`) | ✅ Готово |
| 1.3 | Наполнение 60 базовыми цветами по 8 группам | ✅ Готово |
| 1.4 | Единый сервис `UnifiedLibraryService` (встроенные + пользовательские) | ✅ Готово |

**Что создано:**
- `LibraryManifest` — метаданные библиотеки (версия, количество элементов, группы цветов)
- `DesignLibrary` — агрегирующая модель с сериализацией (fromJson / toJson)
- `BuiltinLibraryService` — загрузка встроенных данных из типизированного списка и JSON
- `UnifiedLibraryService` — единая точка доступа, объединяет встроенные и пользовательские данные
- 60 встроенных цветов: 8 красных, 8 розовых, 8 нюд, 8 фиолетовых, 8 синих, 7 зелёных, 7 жёлтых, 6 тёмных
- 5 встроенных материалов: Гель-лак, Гель, Акрил, Биогель, Обычный лак
- 7 встроенных паттернов: без рисунка, френч, омбре, полоски, точки, мрамор, блёстки

**Архитектурные решения:**
- Цвета хранятся в типизированном Dart-файле (`builtin_colors.dart`), а не в JSON — для производительности и типобезопасности
- Материалы и паттерны — в JSON-строке (`default_library_data.dart`) — для гибкости расширения
- `UnifiedLibraryService` кэширует результат; при изменении пользовательских данных вызывается `invalidateCache()`
- Существующий `LibraryService` продолжает управлять пользовательскими данными, `UnifiedLibraryService` объединяет их с встроенными

## 🔧 Технические заметки

### Использование библиотеки в коде:
```dart
// Получить все цвета для отображения
final colors = await UnifiedLibraryService.getAllColors();

// Получить цвета конкретной группы
final redColors = await UnifiedLibraryService.getColorsByGroup('Красные');

// Найти цвет по ID
final color = await UnifiedLibraryService.findColorById('builtin_red_classic');

// После добавления нового цвета пользователем:
await LibraryService.addCustomColor(name, color);
UnifiedLibraryService.invalidateCache(); // сброс кэша

// Полная перезагрузка
final library = await UnifiedLibraryService.reload();

Зависимости:
path_provider — для хранения JSON-файлов пользовательских данных
hive — локальная база данных клиентов и визитов
gal — сохранение изображений в галерею
flutter_quick_video_encoder — кодирование видео
