# 📘 Паспорт Этапа 3 — Единая Библиотека мастера

> **Цель этапа:** мастер сам наполняет приложение цветами, материалами и рисунками; всё хранится в одном месте и используется во всех точках входа.
> **Архитектурный принцип:** одна база (`library.json` + Hive `my_designs`) = все пикеры видят один контент; удаление в одном месте = исчезновение во всех.

---

## 🎨 3.1 Цвет из фото

**Путь:** Пикер цветов → вкладка «💾 Мои цвета» (первая в списке) → FAB «+» → фото бутылочки/палитры.

**Механика:**
- Тап по фото = точка, **усреднение по площадке 7×7 пикселей** (без шума матрицы)
- 1–5 точек → цвет как среднее
- 3 слайдера коррекции: **Оттенок / Насыщенность / Светлее** — доводка до «как в жизни»
- Авто-имя: `Из фото • 10 сен` + подсказка ближайшего встроенного цвета
- Подсказка «Дневной свет у окна = самый честный цвет»
- Сохранение через `UnifiedLibraryService.addCustomColor` с описанием (HEX + пометка коррекции)

**Фикс точности:** раньше брался один пиксель — получался шум; плюс камера врёт в балансе белого — коррекция HSL это компенсирует.

## 💎 3.2 Свои материалы

**Путь:** Выбор дизайна → Материал → пикер материалов → «+» в AppBar **или** плитка «Создать материал» в конце списка.

**Экран редактора:**
- Живой ноготь-превью сверху (бордовая подложка + форма + эффекты материала)
- 5 пресетов-заготовок: Гель-лак / Матовый топ / Хром / Велюр / Нюд (один тап = старт)
- Слайдеры: Прозрачность / Насыщенность / Интенсивность глянца + переключатель Глянец
- В списке пикера: бейдж «мой» + долгое нажатие = удаление с подтверждением

---

## 🖼 3.3 Свои картинки-узоры

**Архитектурное решение:** картинки хранятся в **той же базе MyDesign**, что и дизайны-рецепты (тип `image`). Не городили вторую секцию в `library.json` — одно хранилище, одно удаление, картинки доступны из «Моих дизайнов» и из пикера узоров одновременно.

**Путь:** Выбор дизайна → Рисунок → раздел «Мои картинки» → плитка «Добавить» (галерея/камера) → имя → сразу выбрана.

**Особенности:**
- PNG с прозрачностью ложится как слайдер-дизайн
- JPG/фото ложится как принт-заливка
- **Явная взаимоблокировка**: выбор векторного узора снимает картинку, выбор картинки снимает узор — результат возвращается в `PatternPickResult` одним объектом
- Долгое нажатие = удаление с подтверждением

### 🧹 3.3b Chroma-key «Убрать белый фон»

**Галочка в обоих диалогах загрузки** (пикер узоров и экран «Мои дизайны»), по умолчанию выключена. При включении:
- Байты проходят через `ChromaKey.removeWhiteBackground` **один раз** при импорте
- Алгоритм: белые (lum ≥ 245) нейтральные (разброс каналов < 40) пиксели → альфа 0; зона 200–245 → плавная полупрозрачность (мягкий край без ореолов); цветные пиксели не трогаем
- Свой PNG-энкодер на `dart:io` (zlib + CRC32) — обошлись без спорных API `decodeImageFromPixels`
- В хранилище уходит уже прозрачная картинка → ноль затрат на рендер дальше

## 🎛 UX примерки (новый низ панели)

1. **Большая кнопка дизайна** во всю ширину с градиентом розовый → фиолетовый, подпись «Дизайн: Бордовый • Матовый топ» (видна и в свёрнутой панели)
2. **Ряд из 4 равных чипов:** 3D | Формы | Кутикула | **Узор**
3. **Режим «Узор»:** слайдеры Прозрачность (0–100%) и Размер (50–200%) + подсказка «Работает для PNG-картинок и векторных узоров»
4. **Слой «Узор»** в панели слоёв (между Рамкой и Кутикулой) — скрывает узор в превью для сравнения «с узором / без»
5. **Регуляторы узора в сессии** (`TryOnSession.patternOpacity`, `patternScale`) — переживают выход и перезапуск

## 🧱 Архитектурные принципы Этапа 3

1. **Единая библиотека** (`UnifiedLibraryService`) — фасад над `LibraryService` (JSON-манифест) + `BuiltinLibraryService` (встроенные данные). Все экраны идут только через фасад.
2. **Одно хранилище картинок-дизайнов** — секция `MyDesign` типа `image`. Пикер узоров и «Мои дизайны» работают с одной базой.
3. **Резолв старых ID** — `resolveColor(id)` и `resolveMaterial(id)` ищут сначала в новой библиотеке, потом в архиве старых ID, потом в тренд-палитрах. Миграция незаметна для пользователя.
4. **Сброс кэша** — `invalidateCache()` вызывается после любого изменения пользовательских данных.
5. **Единые тосты** — `TopMessage.show(context, text, color: …)` — все экраны, единое поведение, центрирование, иконка по цвету.
