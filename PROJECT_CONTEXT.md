## ✅ Реализованный функционал

### 1. Примерка дизайна (EditScreen → ResultScreen)
- Загрузка фото пальца (камера / галерея)
- Pinch-to-zoom и перемещение фото жестами
- Настраиваемая рамка ногтя (ширина, высота, поворот, позиция)
- 5 форм ногтя: Овальная, Круглая, Квадратная, Мягкий квадрат, Квадратно-овальная (анатомически правильные: низ всегда скруглён)
- Кнопка 👁 скрытия рамки для оценки результата
- WYSIWYG: что видишь в настройке = что получаешь в результате = что сохраняется
- **Сессия примерки (НОВОЕ):** состояние (фото, рамка, зум, дизайн, 3D, кутикула) сохраняется в Hive при любом выходе; при входе — диалог «Продолжить / Начать заново»; переживает перезапуск приложения
- **Быстрое меню (НОВОЕ):** из примерки открываются «Клиенты» и «Мои дизайны» поверх (примерка остаётся в стеке — состояние не теряется)
- **Реалистичный 3D-рендер (НОВОЕ):** см. раздел «3D-пакет» ниже

### 2. Выбор дизайна (DesignSelectionScreen)
- Цвет: 60 встроенных цветов в 8 группах + трендовые палитры + группа «Мои цвета»
- Материал: 5 типов (Гель-лак, Гель, Акрил, Биогель, Обычный лак) с визуальными эффектами (глянец, матовость, прозрачность)
- Рисунок: 7 базовых паттернов (френч, омбре, полоски, точки, мрамор, блёстки, без рисунка) + узоры-картинки
- Все данные берутся из **Единой Библиотеки** (`UnifiedLibraryService`)
- Превью сохранённых рецептов — WYSIWYG через тот же `Nail3DRenderer`, что и примерка

### 3. Миксер цветов (ColorMixerScreen)
- Смешивание двух цветов (A + B) с ползунком пропорции
- Добавление белил и затемнения
- Сохранение результата в «Мои цвета» (через `LibraryService`)

### 4. Клиенты и визиты (ClientDetailScreen)
- Локальная база клиентов (Hive)
- Добавление/удаление клиентов
- Визиты с тремя фото: ДО / ПРИМЕРКА / ПОСЛЕ
- Полноэкранный просмотр фото с жестами зума
- Управление фото: удаление (с подтверждением) и замена из галереи
- Автоудаление пустого визита (клиент остаётся)

### 5. Выравнивание «ПОСЛЕ» по призраку (AlignAfterScreen)
- Выбор фото «после» ТОЛЬКО из галереи
- Полупрозрачный контур «ДО» поверх нового фото
- Жесты перемещения и зума для совмещения рук

### 6. Сохранение
- Сохранить клиенту: рендер примерки + фото «до» в базу (с одинаковым зумом мастера)
- В коллекцию: сохранение рецепта дизайна (цвет+материал+форма+3D+узор)
- В галерею: сохранение PNG-рендера через пакет gal

### 7. Видео до/после (AnimationScreen) — В РАЗРАБОТКЕ
- Автоматическая анимация из фото визита
- 7 переходов: Блёстки, Круг, Вспышка, Шторка, Зум-панч, Слайд, Фейд
- 4 шаблона: Чистый (480×640), Instagram (640×640), TikTok (480×854), Гламур (480×640 с искрами)
- Ken Burns эффект (кадры «дышат»)
- Только MP4 экспорт через flutter_quick_video_encoder (без GIF)
- Сохранение в галерею + шеринг

### 8. Единая Библиотека (Этап 1) — НОВОЕ
- `LibraryManifest` — метаданные (версия схемы, счётчики, группы цветов, дата обновления)
- `DesignLibrary` — агрегатор (цвета+материалы+паттерны) с fromJson/toJson и геттерами
- `BuiltinLibraryService` — встроенные данные: цвета из типизированного Dart-списка, материалы/паттерны из JSON-строки (без assets, мгновенно)
- `UnifiedLibraryService` — единая точка доступа: встроенные + пользовательские данные; кэш с `invalidateCache()`
- **Миграция старых ID:** `resolveColor()/resolveMaterial()` ищут: кэш библиотеки → старый `DesignSetsService` → трендовые палитры. Старые сохранения рецептов работают без конвертации БД
- Состав: 60 цветов (8 красных, 8 розовых, 8 нюд, 8 фиолетовых, 8 синих, 7 зелёных, 7 жёлтых, 6 тёмных), 5 материалов, 7 паттернов

### 9. Реалистичный 3D-рендер («3D-пакет») — НОВОЕ
- **Объём без чёрных оверлеев:** затемнение/осветление производными тонами самого лака (hue и saturation сохраняются — цвет не «выцветает»)
- **Поперечный купол (C-изгиб):** светлая узкая ось, бока плавно уходят в тёмный того же тона
- **Продольная арка по анатомии:** низ = кутикула (тень кожного валика, нарастает к основанию), верх = свободный край (светлая кромка торца + тонкая глубина под ней)
- **Внутреннее свечение:** слабый радиальный светлый тон в центре — глубина полупрозрачного геля
- **Живой блик:** наклонная световая полоса (blur ∝ размеру ногтя) + зеркальное гало + резкое ядро («мокрый» глянец); размер/резкость адаптируются к светлоте цвета; интенсивность фильтруется глянцем материала (матовый почти не бликует)
- **Тени:** амбиент-тень вокруг всего контура (ноготь «вдавлен» в палец) + направленная тень снизу
- **Бороздка кутикулы:** рисуется ТОЛЬКО у основания ногтя (свободный край не контактирует с кожей) — эффект «наклейки» устранён
- Ползунки без изменений: «Объём» = купол+арка, «Блик» = зеркало, «Тень» = контактные тени

## 🔧 Технические заметки

### Единая Библиотека — использование
```dart
// Все цвета (встроенные + пользовательские)
final colors = await UnifiedLibraryService.getAllColors();

// Цвета группы
final reds = await UnifiedLibraryService.getColorsByGroup('Красные');

// Синхронный резолвер с поддержкой старых ID (классика + тренды)
final color = UnifiedLibraryService.resolveColor('red_wine');   // legacy
final color2 = UnifiedLibraryService.resolveColor('builtin_red_classic'); // новый

// После изменения пользовательских данных
UnifiedLibraryService.invalidateCache();
```

### Сессия примерки
- Хранилище: Hive box `tryon_session`, ключ `current`
- Фото копируется в `photos/tryon_*` (переживает очистку temp-файлов камеры/галереи)
- Сохранение: `dispose()` EditScreen + перед переходом в ResultScreen
- Вход: `TryOnEntry.launch(context)` — диалог «Продолжить / Начать заново», если сессия жива
- Быстрое меню примерки (⋮): Клиенты, Мои дизайны — открываются поверх, примерка остаётся в стеке

### Модель рендера (SelectedDesign.getRender)
- `layerCoverage`: 1 слой → 0.88, 2 → 0.96, 3 → 1.00 (укрывистость как у реального гель-лака)
- `opacity = material.opacity × layerCoverage` (шейер-материалы остаются полупрозрачными)
- Насыщенность = **множитель** исходной (фикс бага: серый → бордо из-за hue=0 при абсолютной насыщенности)
- Яркость = множитель lightness (0.7–1.3)

### Слои RealisticNailPainter
1. Базовый цвет (с opacity рендера)
2. Поперечный купол (C-изгиб) — производные тона лака
3. Продольная арка — тень валика внизу (кутикула), глубина под кромкой торца вверху
4. Внутреннее свечение (глубина геля)
5. Паттерн (векторный)
6. Живой блик: световая полоса + гало + резкое ядро + кромка торца
7. Глянец материала

### Анатомия координат painter'а
- **НИЗ ногтя (y = height)** = кутикула (скруглённый конец)
- **ВЕРХ ногтя (y = 0)** = свободный край (торец)

### Z-порядок в EditScreen (Stack)
1. Фон (фото) → 2. Ноготь → 3. Подсказка жестов → 4. Панель слоёв → 5. Нижняя панель
